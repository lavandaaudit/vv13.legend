# VV13.ROOM15 — Частина 4 «ПРОБУДЖЕННЯ» + Частина 5 «СХОДОВА КЛІТКА» + Акт III (v1.1)

PS1-style first-person horror. Харківська хрущовка, квартира №8, експеримент ВВ-13 і сутність НУЛЬ.
Одна сторінка гри + окремі моделі — все працює прямо з GitHub Pages.

**v1.1 (21.11.2026)** — велике оновлення за правками гравця: тріпи, нічне самосвітіння,
огляд предметів 3D, заставка старту, стиснений під'їзд, вода у світах, фікс проходу в кладовку,
фікс телепорту-бага у світах, без процедурної музики.

## Запуск

**GitHub Pages:** просто увімкни Pages у налаштуваннях репозиторію (гілка `main`, корінь `/`).
Користувач відкриває `https://<user>.github.io/<repo>/` → ретро-лендінг з консоллю → «ГРАТИ».

**Локально:**

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000/
```

⚠️ Через `file://` моделі не завантажаться (fetch блокується браузером) — потрібен http-сервер.


## Гра

- Старт 16:20 у квартирі №8; час іде сам (2 хв гри за реальну секунду), погода змінюється сама
  (дощ → гроза → туман → сніг). Заставка старту: «ТИ НА VV13» → 16:20 → «ЧИ ЦЕ СОН? МАБУДЬ.»
- Акт I: документ ВВ-13/03 → 5 доказів → дзеркало К2 → касета «ЗРАЗОК 08-В» → ключ-картка зі щитка →
  вихідні двері. 8 доказів у щоденнику [J].
- Акт II «Сходова клітка» (стиснена у 3 рази за планом): 15 ящиків (у кожного лор) → дзеркало 9-ї
  (механіка «не дивись довго») → лом → 3 касети Толіка у кв.12 → люда.
- Акт III «ROOM-15»: 15 капсул → діалог з суб'єктом 07 → РР-7 → пульт, ТРИ ФІНАЛИ:
  СТРАЖ / СТЕРТИ / СТАТИ НУЛЄМ.
- Три фінали. Один день 41. Він навчається.

## НОВЕ У v1.1 (правки гравця)

- **ТРІПИ (видіння)** — 6 типів, кожен запам'ятовується по своїх ефектах:
  1. **ТІНІ ПОДВІЙНИКІВ** — силуети по кутках; подивився прямо 0.5 с — зникають.
  2. **ЛЕВІТАЦІЯ** — дрібні предмети злітають і кружляють.
  3. **ПРОРОСТАННЯ** — трава проростає на стінах (42 % лишається після тріпу).
  4. **ЗСУВ** — меблі їдуть у нові місця НАЗАВЖДИ + пульсації інверсії кольору.
  5. **ВУЛИЦЯ** — гравця випускає надвір: двір, вікна квартири «дивляться», через 2 ігрові
     години (або самостійним входом) телепорт назад у випадкову кімнату.
  6. **ЕХО** — кроки відповідають із запізненням, шепот повторює тебе.
  Тривалість 3-4 ігрові години, періодичність — раз на 1-2 доби, будь-який час доби.
  Під час тріпу: меблі пересовуються і ЗАЛИШАЮТЬСЯ, з'являються нові предмети,
  старі підказки переїжджають на нові місця, одна з дверей може опинитися заваленою —
  до наступного тріпу (загадка). Тріп-стан зберігається у сейвах.
- **СВІТЛО**: вимикачі прибрано. Вдень видно і так; вночі — ліхтарик, а лампи час від часу
  вмикаються САМІ: тускле миготіння різними кольорами (теплий/холодний/зелений/червоний/бузковий)
  з глітчами і зникають, у різних кімнатах.
- **ОГЛЯД ПРЕДМЕТІВ 3D**: підібрав предмет — модель відкривається у вікні огляду, можна крутити
  мишею/пальцем.
- **РЮКЗАК**: кнопка «✕ ЗАКРИТИ ВІКНО»; ESC закриває верхнє відкрите вікно (інспект → рюкзак →
  огляд → щоденник → панель системи).
- **МУЗИКА**: процедурний дрон видалено — лишилися тільки реальні звуки Freesound.
- **СИДІННЯ**: огляд тепер і вліво/вправо (±66° від напрямку місця).
- **МОБІЛЬНІ КНОПКИ**: прибрано зайві (ЗВУК, МЕБЛІ, 180°, ЧАС), лишилися СІСТИ · ЛЕГТИ · ДВЕРІ ·
  ЛІХТ + ВЗЯТИ · РЮКЗАК · ЩОДЕННИК; зменшені і підняті вгору — не заважають свайпу огляду.
- **ЛІХТАРИК ЗБЛИЗУ**: фікс — руки від 1-ї особи більше не кидають тінь-конус уперед,
  предмет у упор більше не «чорний».
- **ЗАСТАВКА СТАРТУ**: кіно-інтро поки вантажаться моделі, клік — пропустити.
- **ПІД'ЇЗД СТИСНУТО У 3 РАЗИ** за планом (висоти і меблі — людські), плюс 3 точки води у світах.
- **ФІКС ПРОХОДУ**: ящики/полиця/верстат у кладовці не стоять більше на лінії дверей —
  усі колайдери по стінах, центр вільний; кухонний стіл переїхав на південь.
- **ФІКС ТЕЛЕПОРТУ-БАГА**: межі руху тепер світозалежні — у під'їзді/підвалі гравця більше
  не кидає у кут квартири при першому натисканні W (керівний clamp тільки у кв. №8).
- **ФІКС ПОГУЖОГО «F»**: перемикання меблів більше не знищує колайдери нових світів.
- Тексти: «відображення», «пластикова», «Булава», єдине «касета»; title без «Демо Б».
- 16 відсутніх у repo моделей замінено на наявні (kрісло → mid_century_lounge_chair,
  катана → ornate_medieval_mace, барелі → trashbag/propane_tank тощо) — 0 запитів 404.

## Виживання героя

- **4 стани** (бари ліворуч зверху): СИЛИ · ЇЖА · ВОДА · СТРАХ. Хоче пити → рух ×0.65;
  голодний → ×0.5; нема сил → не бігає; страх >60 → глітчі і шепіт, >85 → скрімер-встряски.
  Лежиш/сидиш → сили відновлюються, страх спадає.
- **Пошук ресурсів [R]**: вода і їжа по квартирі + 3 точки води у нових світах; інгредієнти:
  ганчірки, спирт, батарейки, листочки (ейфорія).
- **Рюкзак [B]**: використання, нотатки-підказки, крафт: БИНТ, КАПЛІ «ТРАВОКА», ЗАРЯД ФОНАРЯ.
- **Сон [R]** на кушетці/диванах: +5 годин, сили 100, страх −35.
- **Меблі [R]**: сісти на стільці/крісло (огляд ±66°), легти на диванах; лежати в темряві довго —
  у дверях хтось з'являється.
- **Огляд предметів [R]** біля 15 точок + 3D-інспектор після підбору.

## НУЛЬ (сталкер)

- «Навчається» на діях гравця: агресія росте від дзеркал/шуму/бігу, падає від спокою.
- Віз-ангел: не рухається, поки на нього дивляться.
- Червоний далекий промінь відганяє, близький — глушить на 1.6 с.
- Булава: 2 удари (кожен −18 стаміни). Контакт = СМЕРТЬ: «День 41 повторюється»,
  рестарт від автосейву; агресія переживає смерть.

## Технічні нотатки

- Three.js r128 + GLTFLoader зашиті в `game.html` (не CDN — працює без інтернету).
- Моделі завантажуються `fetch('models/<name>.gltf')`; текстури вшиті base64 у сторінку.
- Колайдери меблів рахуються після завантаження всіх моделей (phPending-гейт).
- Шари коду: движок → Акт I → виживання → огляд 3D → тріпи → світи → НУЛЬ → акти II-III → системи.
- Тестові параметри URL: `?shot=1` (без вступу), `?dark=1`, `?weather=0..5`, `?time=15.5`,
  `?trip=1` (тріп майже одразу), `?bright=1` (дев-підсвітка).
- Дебаг-хуки (для тестів): `window.__tripDebug.force(t)/stop()`, `__nightDebug.force()`,
  `__enterStair/__enterBase`, `__nullState`, `__wstat`, `__vv13.state`, `__survState`.
