# VV13.ROOM15 — Частина 4 «ПРОБУДЖЕННЯ»

PS1-style first-person horror. Харківська хрущовка, квартира №8, експеримент ВВ-13 і сутність НУЛЬ.
Одна сторінка гри + окремі моделі — все працює прямо з GitHub Pages.

## Запуск

**GitHub Pages:** просто увімкни Pages у налаштуваннях репозиторію (гілка `main`, корінь `/`).
Користувач відкриває `https://<user>.github.io/<repo>/` → читає опис → «ГРАТИ».

**Локально:**

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000/
```

⚠️ Через `file://` моделі не завантажаться (fetch блокується браузером) — потрібен http-сервер.

## Структура

```
index.html          — сторінка гри: опис сюжету, керування, «ГРАТИ» вгорі й унизу
game.html           — сама гра (1.2 МБ): движок, квест акта I, події, збереження
models/             — 172 GLTF-моделі Poly Haven (CC0), буфери зашиті в json
  textures/         — ~200 текстур (JPG 384–512px) для моделей
sounds/             — 11 реальних звуків Freesound (кредити нижче)
README.md
```

## Гра (Акт I «ПРОБУДЖЕННЯ»)

- Старт 16:20 у квартирі №8; час іде сам, погода змінюється сама (дощ → гроза → туман → сніг).
- 6 завдань: документ ВВ-13/03 → 5 доказів → дзеркало К2 → касета «ЗРАЗОК 08-В» у телевізор →
  ключ-картка зі щитка кладовки → вихідні двері.
- 8 доказів у щоденнику [J] з текстами біблії (НУЛЬ, подвійники, сусід з 9-ї, зразок 08-В).
- Темрява: вимикачі [E] реально гасять кімнати (лампи прив'язані до кімнат).
- Ліхтарик [L]: ТЕПЛИЙ БЛ/ДАЛ → ЧЕРВОНИЙ БЛ/ДАЛ → МИГАННЯ → ВИМК.

## Виживання героя

- **4 стани** (бари ліворуч зверху): СИЛИ · ЇЖА · ВОДА · СТРАХ — деградують з часом.
  Хоче пити → рух ×0.65; голодний → ×0.5; нема сил → не бігає; страх >60 → глітчі і шепіт,
  >85 → скрімер-встряски. Лежиш/сидиш → сили відновлюються, страх спадає.
- **Пошук ресурсів** [R]: вода і їжа по квартирі (кухня, ванна, балкон) + інгредієнти:
  ганчірки, спирт, батарейки, листочки (ейфорія — голод/спрага повільніші, страх тане).
- **Рюкзак** [B] / мобільна кнопка РЮКЗАК: інвентар з використанням, нотатки-підказки,
  **крафт**: БИНТ (ганчірка+спирт, −страх), КАПЛІ «ТРАВОКА» (листочок+вода),
  ЗАРЯД ФОНАРЯ (2 батарейки — промінь ×1.6 на 4 хв).
- **Сон** [R] на кушетці К2 / диванах: +5 годин, сили 100, страх −35, голод/спрага падають.
- **Меблі** [R]: сісти на 8 стільців/крісло (оглянеш кімнату, відпочинок), легти на диванах/лежаку;
  лежати в темряві довго — у дверях хтось з'являється.
- **Огляд предметів** [R] біля 15 точок: картини (ліс-догори-ногами, дитячий малюнок з 15 вікнами,
  портрет матері з касетою), статуї (готична «кімната спокою», кіт «09», знак ВВ-13), шахи що
  грають самі, годинник на 16:20, набір хіміка з формулами РР-7, **скриня в кладовці — відмикається
  ключ-карткою 08** (нотатка про 15 секцій). Лор додається в рюкзак.
- Події: скрімер у дзеркалі, силует у вікні (ніч/гроза), VHS-глітчі, стук у стіни, шепіт,
  дзвінок, дитячий сміх, двері що відкриваються самі.
- Автозбереження (localStorage, включно з рюкзаком і статами) — кнопка «ПРОДОВЖИТИ» на старті.
- Фінал акта I: картка зі статистикою + тізер «ЧАСТИНА 5 — СХОДОВА КЛІТКА».

## Технічні нотатки

- Three.js r128 + GLTFLoader зашиті в `game.html` (не CDN — працює без інтернету).
- Моделі завантажуються `fetch('models/<name>.gltf')`; текстури — `models/textures/*.jpg`
  через resourcePath `'models/'`.
- Колайдери меблів рахуються після завантаження всіх моделей (phPending-гейт).
- Тестові параметри URL: `?shot=1` (без вступу), `?dark=1` (всі кімнати темні),
  `?weather=0..5`, `?time=15.5` (година старту), `?bright=1` (дев-підсвітка).

## Моделі

Poly Haven CC0 (`polyhaven.com`) — 58 моделей: меблі, декор, техніка, інструменти.
Конвертація: glTF 1k, текстури 512–1k JPG.
